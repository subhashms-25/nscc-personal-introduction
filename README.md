# Personal Introduction Website

This is a simple responsive personal introduction website created for the
NSCC SRM Technical Domain recruitment task.

## Features

- Photo section
- Personal introduction
- Interests
- Currently learning section
- LinkedIn and email links
- Responsive layout for smaller screens
- Dark and light mode
- Theme preference saved using localStorage

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. You can also use the Live Server extension in VS Code.

## Files

- `index.html` - webpage structure and content
- `style.css` - webpage appearance and responsive design
- `script.js` - dark/light mode functionality
- `CI.png` - profile photo
- `README.md` - project information
